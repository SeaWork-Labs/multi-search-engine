# 多引擎搜索

Multi search engine integration with 17 engines. No API keys required.

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/multi-search-engine#v2.1.9 --skill multi-search-engine
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill multi-search-engine
```

## 内容

技能正文在 `skills/multi-search-engine/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/multi-search-engine/payload/`，不要反向同步。版本以 git tag 为准。
